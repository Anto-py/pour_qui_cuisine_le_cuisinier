# Pour qui cuisine le cuisinier ?

Un explainer à défilement (scrollytelling) tout public : ce qu'est un algorithme, et pour qui il travaille.

La métaphore du restaurant est celle de Damien Van Achter : [« Un algorithme est comme un cuisinier. Mais pour qui cuisine-t-il vraiment ? »](https://da.van.ac/un-algorithme-est-comme-un-cuisinier-mais-pour-qui-cuisine-t-il-vraiment/). Sa lettre d'information : <https://da.van.ac/#/portal/signup>.

## Ouvrir la page

HTML, CSS et JavaScript natifs, sans dépendance ni étape de construction. Servir le dossier avec n'importe quel serveur statique, par exemple :

```bash
python3 -m http.server
```

puis ouvrir `http://localhost:8000/`. Pensée pour un écran d'ordinateur. On avance en faisant défiler, ou avec les flèches `←` et `→`.
